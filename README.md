# World Bank: GDP per capita in 15 European countries

Анализ ВВП на душу населения в 15 европейских странах по данным **World Bank** за **2015–2024 годы**. Проект выполнен в Python с использованием pandas и matplotlib.

## Цель

Сравнить уровень ВВП на душу населения между странами, посмотреть динамику показателя и научиться проводить базовую проверку качества данных.

## Что сделано

- Загрузка данных из официального API World Bank.
- Проверка структуры таблицы: типы данных, пропущенные значения и дубликаты.
- Очистка и подготовка данных с помощью pandas.
- Сравнение стран за 2024 год и расчёт описательных статистик.
- Сопоставление значений за 2015 и 2024 годы.
- Построение графиков и формулирование выводов.

## Страны

Германия, Франция, Италия, Испания, Великобритания, Нидерланды, Бельгия, Австрия, Португалия, Польша, Чехия, Дания, Швеция, Финляндия и Норвегия.

## Как запустить

1. Скачайте проект и откройте папку в терминале.
2. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите Jupyter:
   ```bash
   jupyter lab
   ```
4. Откройте **`world_bank_gdp_analysis.ipynb`** и выполните ячейки сверху вниз.

При первом запуске ноутбук скачает данные World Bank и сохранит их в `data/`. Нужен интернет. При следующих запусках сначала используется локальная копия CSV. Чтобы получить свежие данные, удалите `data/world_bank_gdp_per_capita_raw.csv` и повторите запуск.

Графики сохраняются в `figures/`, очищенные данные — в `data/world_bank_gdp_per_capita_clean.csv`.

## Используемые технологии

`Python` · `pandas` · `matplotlib` · `requests` · `Jupyter Notebook`

## Источник данных

**World Bank — World Development Indicators**

- Показатель: **NY.GDP.PCAP.CD — GDP per capita (current US$)**
- Описание: https://data.worldbank.org/indicator/NY.GDP.PCAP.CD
- Официальный API: https://api.worldbank.org/v2/country/DEU/indicator/NY.GDP.PCAP.CD?format=json
- Документация API: https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures
- Лицензия данных: **CC BY 4.0** (World Bank)

**Важно:** показатель выражен в *текущих долларах США*. Его изменение отражает не только реальные изменения экономики, но также динамику цен и валютных курсов. Поэтому процентное изменение в этом анализе **не интерпретируется как реальный экономический рост**.

Данные World Bank могут пересматриваться, поэтому цифры при повторной загрузке способны немного измениться.
